# 서식 예시

전역 지침의 서식 규칙에서 분리한 수정 대상 예시와 치환 예시이다.
소제목은 서식 규칙의 소제목과 같다.

## 문장 구조

- e.g. 내·외부, 상·중·하위권

## 문장 표현

### 영어식 표현 및 은유, 단어 직역 수정

- 수정 대상 예시: `짚다`(point out), `걸치다`(cover, across, span), `닫다`(close), `닿다`(touch),  
  `흔들리다`(axis/pivot/baseline shift, wobble), `맞닿다`(meet, touch), `지원하다`(support), `확보하다`(ensure)
  - `짚다` → `지적하다`, `확인하다`, `설명하다`
  - `걸치다` → `포함하다`, `진행하다`, `적용하다`, `변경하다`, `연결하다`, `아우르다`
  - `판단의 축이 흔들린다` → `판단 기준이 바뀐다`
  - `내용을 짚는다` → `내용을 확인한다`
  - `판단을 닫는다` → `결론을 내린다`
  - `수정이 닿는다` → `수정에 영향을 받는다`
  - `세 파일에 걸쳐 변경한다` → `세 파일을 변경한다`
  - `빠른 탐색을 지원한다` → `문서 제목으로 검색할 수 있다`
  - `디자인의 일관성을 확보한다` → `동일한 디자인 기준을 적용한다`
- `canonical` → 기준, 표준, 규격 등
- `template` → 템플릿, 서식, 템플릿 등
- 비기술적 `transition` → 이동, 전환, 변경 등
- 문서가 아닌 파일의 `full text`, `entire content` → 파일 전체 내용 등

### 구체적인 대상과 행위 표현

- `문장에 꼬리표를 붙인다` → `문장 끝에 [해결]을 표시한다`
- `갈래` → `유형`, `범주`
- 수정 대상 예시: 개인정보, 보안 정보, 세션 외부 경로, 개인 폴더명, 세션 식별자와 본문, 사용자 메시지, 기타 비공개 정보
- `모으다` → 수집하다, 집계하다 / `싣다` → 불러오다, 기록하다 / `붙이다` → 추가하다, 연결하다
- `넣다` → 입력하다, 저장하다 / `빼다` → 제거하다, 추출하다 / `뽑다` → 추출하다, 선별하다
- `묶다` → 그룹화하다, 결합하다 / `돌리다` → 실행하다, 반복하다 / `넘기다` → 전달하다, 위임하다
- `고치다` → 수정하다, 해결하다 / `만들다` → 생성하다, 구현하다, 정의하다
- `쓰다` → 작성하다, 기록하다, 서술하다, 지정하다, 명시하다, 정의하다, 사용하다, 적용하다 (`read/write` 문맥 제외)

### 기술 맥락에 맞는 용어 선택

- `Approval Gate` → `승인 게이트`
- `Test Case` → `테스트 케이스`
- `Override` → `오버라이드` 또는 원문 유지
- `Source of Truth` → 원문 유지
- `짝짓는다` → `매핑한다`
- `화면을 그린다` → `렌더링한다`

### `~내다` 표현의 한정 사용

- 수정 대상 예시: `녹여내다`, `담아내다`, `풀어내다`, `그려내다`, `빚어내다`, `끌어내다`, `펼쳐내다`
- `복잡한 문제를 풀어낸다` → (해결한 문제와 해결 방법을 구체적으로 설명)

### 피동 표현과 조사의 사용

- `결과는 대시보드에서 보여진다` → `결과는 대시보드에 표시된다`

### 행위 동사 우선 사용

- `조사를 진행한다` → `조사한다`
- `분석을 수행한다` → `분석한다`
- `수정 작업이 이루어졌다` → `수정했다`

### 단정 회피 표현의 수정

- 수정 대상 예시: `단정할 수 없다`, `확언하기 어렵다`, `가능성을 배제할 수 없다`
- `원인을 단정할 수 없다` → `오류 발생 시점의 요청 로그가 없어 원인을 확인하지 못했다`

### 형식적인 역접 표현의 제거

- 수정 대상 예시: `다만`, `하지만`, `물론`, `한편` 등
- `수정했습니다. 다만 정상 동작을 보장할 수 없습니다` → (수정 범위와 검증 결과를 각각 설명)

### 확인 유보 표현의 구체화

- 수정 대상 예시: `추가 확인이 필요하다`, `검토가 필요하다`, `실제 환경에서 확인이 필요하다`
- `실제 동작의 추가 검증이 필요하다` → `브라우저 Network 패널에서 폼 제출 시 요청 횟수를 확인한다`

### 불필요한 대비 표현의 제거

- 수정 대상 예시: `A가 아니라 B`, `A 대신 B`, `A보다는 B`, `A를 넘어 B`,  
  `A이다. B가 아니다.`, `A이다. B하지 않는다.`
- `단순한 버튼 수정이 아닌 사용자 경험의 근본적 개선` → `폼 제출 중 버튼을 비활성화하고 로딩 표시를 추가`

### 작업 의지 선언의 제한

- 수정 대사 예시: `~하겠습니다`, `~해 보겠습니다`, `~부터 살펴보겠습니다`, `~해야 합니다`

### 검증 상태와 실패 원인 명시

- `환경상 검증하지 못했다` → `테스트 실행 중 DATABASE_URL 미설정 오류로 데이터베이스 연결 단계에서 중단됐다`

### 작업 완료 범위와 결과 보고

- 수정 대상 예시: `완벽하게 수정했다`, `모든 문제를 해결했다`, `안전하게 처리했다`, `문제없이 동작한다`
