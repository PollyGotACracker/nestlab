<!-- 문제 정의 절은 hook이 답에 따라 기록한다. -->

응답 본문 (질문 도구를 띄우는 응답에 먼저 쓴다):

- 한계: <내용 | 없음> (출처: <URL>)
- 위험: <내용 | 없음> (출처: <URL>)

<!-- 내용이 있는 줄의 출처는 http 또는 https URL이다. 없음 줄은 출처를 생략한다. -->

질문:

문제 정의 확인: 문제 <번호>. <확정할 문제와 범위 한 문장> (작업 <MMDD-HHMMSS>)

라벨:

- 확정: 질문의 문제와 범위를 문제 정의에 기록한다.
- 보류: 확정하지 않고 수정 의견을 자유 입력으로 받는다.
- 폐기: 질문의 문제를 문제 정의에 기록하지 않는다.

<!-- 질문 도구는 선택지가 2개 이상이어야 하므로 `보류`를 둔다. 수정 의견은 자유 입력으로 받는다. -->
<!-- 이미 있는 번호는 위 확정 형식으로 다시 묻지 않고 아래 추가 합의 또는 교체 질문을 쓴다. -->

추가 합의 질문 (같은 번호의 원문을 유지하고 하위 줄로 덧붙인다):

문제 정의 확인: 문제 <번호> 추가 합의: <내용> (작업 <MMDD-HHMMSS>)

교체 질문 (같은 번호의 원문을 새 원문으로 바꾸고 이전 확정을 하위 줄로 남긴다):

문제 정의 확인: 문제 <번호> 교체: <새 원문> (작업 <MMDD-HHMMSS>)

폐기 질문:

문제 정의 확인: 문제 <번호> 폐기: <폐기 사유> (작업 <MMDD-HHMMSS>)
