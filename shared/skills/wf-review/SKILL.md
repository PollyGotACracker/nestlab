# 결과물 검수

## 인수

- `입력`: 입력 문서 위치. 이 문서에는 아래 절이 있다.
	- 요구사항: 요구사항별 작업과 검수 항목
	- 검수 계획: 검증 명령
	- 잠재적 위험: 발생 여부를 확인할 위험
	- 재작업 요청: 수정 위치와 기대 결과
	- 재검수 요청: 다시 검수할 항목

## 절차

1. `입력` 문서 요구사항 절의 검수 항목으로 검수 목록을 만든다.
	재작업 요청·재검수 요청 절에 항목이 있으면 그 항목만 재검수한다.
2. 실제 변경 diff, 결과물, 원본, 요구사항이 지정한 기준 자료를 직접 연다.
3. 검수 항목마다 `PASS`·`FAIL`·`미측정`으로 판정하고 확인 위치와 관찰 내용을 적는다.
4. 원본과 결과물을 비교해 요구사항 밖 변경을 모두 `FAIL`로 기록한다.
5. 검수 계획 절의 검증 명령을 실행하고 실행 명령과 결과를 적는다.
6. 잠재적 위험 절의 항목마다 실제로 발생했는지 확인한다.
7. 검수 항목·검증 명령·잠재적 위험에 없는 문제는 판정 대상에서 빼고 `계획 밖 발견`으로 위치와 관찰 내용만 적는다.
8. 검수 대상 파일은 고치지 않고 결함마다 처리 범위를 적는다.
	- 기존 범위에서 해결 가능: 위치, 문제, 기대 결과
	- 요구사항·확정 결정·제약 변경 필요: 변경 항목과 근거
9. 검수 목록 전체, 항목별 판정과 근거, 결함 목록, `계획 밖 발견`을 반환한다.
	`미측정` 항목이 있으면 검수를 미완료로 표시한다.
