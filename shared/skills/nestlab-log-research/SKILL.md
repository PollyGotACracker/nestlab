# 조사 문서

## 작성 시점 규칙

- 착수 단계에서 조사 계획과 프로젝트 환경, 제약 사항을 채운다.
- 조사 단계 원문은 hook이 조사 결과를 저장할 때 채운다.
- 확인 상태와 확인 시각은 사용자가 조사 문서 확인에 답한 턴에 채운다.

## 작성 규칙

- 문서 위치는 프로젝트 전역 지침 경로 목록의 조사 문서이다.
- 반증 회차와 주장 목록은 반증 문서에만 기록한다.
- 추정하거나 확인하지 못한 값은 끝에 `[확인 필요]`를 붙인다.
- 제약과 프로젝트 환경의 항목마다 출처를 적는다.
- 근거 자료는 저장소 파일의 `파일:행`과 외부 링크로 한정한다.
- 조사 항목 제목 끝에 연결한 요구사항을 `(요구사항 <번호>)` 번호로 적는다.
- 조사 계획의 조사 항목에는 착수 조사가 반환한 검토 항목 중 후보 비교가 필요한 항목을 적는다.
- 프로젝트 환경에는 착수 조사가 반환한 저장소 사실과 확인 범위를 `파일:행` 출처와 함께 적는다.
  조사 결과가 새로 반환한 저장소 사실은 함께 이 칸에 추가한다.
- 최종 조사 원문 칸에는 코드 블록 하나만 둔다.
  코드 블록 안이 가로줄 `---`로 나뉘어 있으면 같은 조사 항목은 마지막 구간을 최신 원문으로 본다.
- 사용자 메시지는 핵심만을 요약한다.
- 시각 형식: `<YYYY-MM-DD HH:MM:SS>`

### 사용 커맨드

- 시각(KST): `TZ=KST-9 date '+%Y-%m-%d %H:%M:%S'`
- 기준 커밋: `git log -1 --format=%h`
