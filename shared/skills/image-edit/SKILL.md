# Constrained Image Edit

- 적용 대상은 기존 이미지 일부의 생성형 편집 변경이다.
- 통제 대상은 ImageGen 기반 편집 절차이다.
- 제외 대상은 픽셀 단위 동일성이나 수정 영역 밖 pixel diff=0 보장이다.

## 사용 조건

### 적용 요청

다음 요청에 사용한다.

- 새로운 물체 생성
- 포즈 변경
- 형태 재구성
- 자연스러운 인페인팅
- 그림체 변환
- 원본에 존재하지 않는 시각 요소 생성

### 이관 요청

다음 요청은 `pixel-edit`으로 이관한다.

- 특정 영역의 색상 변경
- 원본 비율의 해상도 유지
- 수정 범위를 지정 영역으로 한정
- 원본 해상도와 비대상 픽셀 보존이 필수인 작업
- 수정 영역 밖 pixel diff=0 검증이 필요한 작업

## 필수 도구

### 편집 도구

다음 도구를 반드시 사용한다.

- 실행 환경에 등록된 ImageGen 편집 도구를 확인하고 실제 호출용 도구 이름을 기록한다.

### 적용 판정

- 적용 판정은 ImageGen 편집 도구 호출 기록으로 한다.
- 적용 기준은 확인한 도구를 통한 EDIT TARGET 실제 편집 기록 최소 1회이다.
- Skill 문서 열람이나 프롬프트 작성만 한 경우는 미적용으로 판정한다.

### 보조 검증 도구

필요 시 다음 도구를 사용한다.

- 실행 환경에 등록된 shell 실행 도구
- Python 3
- Pillow (`PIL`)

### 검증 용도

- 보조 검증 용도는 이미지 크기, 파일 형식, 메타데이터 확인이다.
- 생성형 결과의 보존 범위와 픽셀 동일성 비보장은 12절의 고지 기준(I036)에 따라 보고한다.

## 도구·행동 제한

### 도구 제한

- 단순 색상 치환은 사유가 있는 경우에만 ImageGen으로 처리한다.
- `pixel-edit`에 적합한 요청은 `pixel-edit`으로 처리한다.

### 행동 제한

- 미화, 재디자인, 디테일 추가는 사용자 요청이 있는 경우에만 수행한다.
- Skill 적용 보고는 필수 도구의 실제 호출 후에만 수행한다.
- 해상도·비율이 원본과 다르게 생성된 경우 검증 완료 후 제출한다.

## 역할 고정

여러 이미지가 있는 경우 각 역할을 명시한다.
참조 이미지는 지정된 역할의 특성만 EDIT TARGET에 반영한다.

- `EDIT TARGET`은 실제 수정할 원본이다.
- `SHAPE REFERENCE`로 형태와 비율을 참고한다.
- `STRUCTURE REFERENCE`로 구조를 참고한다.
- `STYLE REFERENCE`로 화풍을 참고한다.

## CHANGE SET

### 기록 대상

사용자가 명시한 수정만 `CHANGE SET`에 기록한다.

e.g. CHANGE SET 기록

```text
CHANGE SET
- 오른쪽 가방 제거
- 눈을 조금 작게 수정
```

### 모호한 요청

- 모호한 요청은 해석에 따라 아래 항목이 달라지는지 확인한다.
  - 수정 대상
  - 형태
  - 정도
  - 보존 범위
- 달라지는 항목이 있는 경우 편집 전 사용자에게 질문한다.
- 확인된 해석으로 CHANGE SET과 PRESERVE SET을 작성한다.

## PRESERVE SET

### 분류 기준

CHANGE SET에 없는 가시 요소는 `PRESERVE SET`으로 분류한다.

e.g. PRESERVE SET 분류

```text
PRESERVE SET
- 캐릭터 정체성
- 전체 레이아웃
- 텍스트 내용
- 의상
- 색상
- 배경
- 카메라 시점
```

### 보존 조건

다음 보존 조건을 적용한다.

- 위치 유지
- 크기 유지
- 형태 유지
- 색상 유지
- 디자인 유지
- 구성 관계 유지
- 텍스트 내용 유지

### 보장 범위

- PRESERVE SET은 시각적 보존 조건이다.
- 픽셀 동일성의 보장 범위에는 12절의 고지 기준(I036)을 적용한다.

## 실행 순서

아래 순서의 모든 단계를 차례로 수행한다.

### 1. 준비 단계

1. EDIT TARGET을 고정한다.
2. 1절의 사용 조건(I001·I002)에 따라 생성형 편집과 결정론적 픽셀 편집의 적합성을 판정한다.
3. 생성형 편집이 맞는 경우 5절의 기준(I009)에 따라 CHANGE SET을 작성한다.
4. 6절의 기준(I011)에 따라 나머지 가시 요소를 PRESERVE SET으로 작성한다.
5. 참조 이미지가 있는 경우 4절의 역할 고정 기준(I007·I008)을 적용한다.

### 2. 실행 단계

1. 2절의 도구 확인·실제 호출 기준(I003)에 따라 EDIT TARGET 편집을 실행한다.

### 3. 판정 단계

1. 결과를 원본 또는 가장 최근 PASS 결과와 비교한다.
2. FAIL 항목이 있는 경우 11절의 기준 이미지·실패 범위 기준(I031)에 따라 재편집한다.
3. 12절의 제출 조건(I034·I035)을 충족한 결과만 제출한다.

## ImageGen 프롬프트 규칙

### 필수 의미

프롬프트에는 다음 의미를 반드시 포함한다.

```text
Edit the existing target image rather than redesigning the subject.
Change only the listed elements.
Keep every unlisted visible element unchanged.
Use each reference image only for its assigned role.
Preserve the original composition, identity, and unrelated details.
```

### 추가 명시

추가로 다음 사항을 명시한다.

- EDIT TARGET이 무엇인지
- CHANGE SET
- PRESERVE SET
- 참조 이미지 역할
- 사용자가 제외를 요청한 변경

## 최소 단위 편집

### 분할 기준

서로 독립적인 변경은 가능한 한 작은 단위로 분할한다.

e.g. 독립 변경 두 개의 분할

1. 눈 크기를 작게 수정한다.
2. 가방만 제거한다.

### 단계별 적용

1. 각 단계에서는 해당 단계의 CHANGE SET만 활성화한다.
2. 다음 단계의 기준 이미지는 11절의 원본·최근 PASS 선택 기준(I031)에 따라 결정한다.

## 결과 검증

### CHANGE CHECK

- CHANGE SET 항목이 요청 범위 안에서 반영됐는지 확인한다.
- CHANGE SET에 명시된 변경 범위·정도와 결과를 비교한다.
  비교 근거가 없는 항목은 아래 판정 기준(I030)에 따라 `[미측정]`으로 기록한다.

### PRESERVATION CHECK

- 요청하지 않은 요소가 추가·삭제됐는지 확인한다.
- 텍스트가 변경됐는지 확인한다.
- 레이아웃이 유의미하게 변경됐는지 확인한다.
- 캐릭터 정체성이 변경됐는지 확인한다.

### REFERENCE CHECK

- 참조 이미지에서 지정 역할 외 특성이 유입됐는지 확인한다.

### 판정 값

판정은 다음 세 값만 사용한다.
실제 비교 근거가 있는 경우에만 PASS를 사용한다.

- `PASS`
- `FAIL`
- `[미측정]`

## 실패 처리

FAIL이 있는 경우 다음 원칙을 적용한다.

### 기준 이미지 선택

1. 실패한 결과는 기준 이미지에서 제외한다.
2. 가장 최근 PASS 결과가 있는 경우 해당 결과를 사용한다.
3. PASS 결과가 없는 경우 원본 EDIT TARGET을 사용한다.

### 재편집 판단

1. 실패한 요소만 다음 CHANGE SET으로 한정한다.
2. 동일 유형의 비의도적 변형이 반복되면 `pixel-edit`으로 해결 가능한지 재판정한다.

## 제출 조건

### 제출 기준

다음 조건을 모두 만족한 경우에만 제출한다.

- 2절의 실제 편집 호출 기준(I003)을 충족하는 호출 기록이 존재한다.
- 필수 CHANGE SET 검증 항목이 모두 PASS이다.
- 필수 PRESERVE SET 검증 항목이 모두 PASS이다.
- 참조 역할을 지킨 결과이다.

### 보류 처리

1. 필수 검증 항목에 FAIL 또는 `[미측정]`이 있는 경우 최종 제출과 완료 보고를 보류한다.
2. 해당 항목과 실제 판정 및 필요한 확인 방법을 고지한다.

### 고지 기준

다음 사항을 명시적으로 고지한다.

- 생성형 편집의 픽셀 단위 동일성은 보장 범위 밖이다.
- 픽셀 단위 보존이 필수이면 `pixel-edit`이 적합하다.

## 적용 증거

### 보고 항목

최종 보고에는 최소한 다음 사항을 기록한다.

```text
사용 Skill: image-edit
필수 편집 도구: <현재 환경에서 확인한 ImageGen 도구 이름>
실제 호출: 완료
검증 기준: CHANGE CHECK / PRESERVATION CHECK
```

### 작성 기준

- 최종 적용 보고에는 2절의 실제 호출 기준(I003)을 적용한다.
- 호출 근거가 없는 경우 문서 열람·프롬프트 작성 등 실제 수행 단계만 보고한다.
