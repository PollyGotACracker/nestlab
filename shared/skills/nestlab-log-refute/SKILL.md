# 반증 문서 양식

## 작성 규칙

- 문서 위치는 프로젝트 전역 지침 경로 목록의 반증 문서이다.
- 조사 단계가 끝나면 director가 이 양식으로 문서를 만들고 조사 문서의 작업 ID를 적는다.
- 주장 목록은 조사 결과 저장 hook이 조사 원문의 주장 목록에서 뽑아 번호와 함께 적는다.
- 회차 기록은 반증 결과 저장 hook이 적는다.
  - 회차는 `조사 및 반증 루프` 절 안의 표 행 수로 센다.
  - 정지 여부는 반증 0건이면 `정지(반증 0건)`, 2회 도달이면 `정지(2회 도달)`, 그 밖에는 `계속`이다.
- 반증 요청 한 줄은 `반증 문서: <반증 문서 경로>` 형식이다.
- 시각 형식: `<YYYY-MM-DD HH:MM:SS>`

## Template

- 아래 코드 블록의 양식을 그대로 쓴다.
- 쓰기 검사 hook이 이 코드 블록의 제목을 필수 절로 검사한다.

````markdown
# 반증 문서: <검토 주제명>

- 작업 ID: <작업-id>

## 주장 목록

<!-- 조사 결과 저장 hook이 조사 원문에서 뽑아 적는다. -->

- 주장 <번호>: <사실 문장> (출처: <URL | 파일:행>)

## 조사 및 반증 루프

<!-- 표 구분자는 `|` 로만 작성한다. -->

| 회차   | 반증 건수 | 정지 여부                            |
| ------ | --------- | ------------------------------------ |
| <회차> | <건수>    | <계속 \| 정지(반증 0건 \| 2회 도달)> |

## 회차 기록

<!-- 반증 회차마다 hook이 `### <n>회차 반증 요청`과 `### <n>회차 반증 원문`을 이 절 끝에 덧붙인다. -->

### <n>회차 반증 요청

```
<반증 요청 원문>
```

### <n>회차 반증 원문

```
- 주장 <번호>: <지지 | 반증 | 미확인> | 출처: <URL 또는 파일:행 | 없음>
```
````
