# 구현

## 절차

1. 구현 기준을 확인한다.
   - 구현 기준은 요구사항별 작업과 검수 항목, 바꿀 수 없는 결정과 제약, 변경 대상과 유지 대상, 승인된 행동과 영향 범위이다.
   - 지정된 수정 항목만 고치는 작업이면 항목마다 수정 위치와 기대 결과를 확인하고 그 항목만 고친 뒤 4단계로 넘어간다.
2. 변경 대상과 유지 대상 안에서 구현한다.
   - 테스트 케이스는 요구사항의 검수 항목을 확인하는 것만 추가한다.
   - 요구사항·결정·제약을 바꿔야 하면 작성을 멈추고 바꿀 항목과 근거를 반환한다.
3. 이번 변경 때문에 어긋난 참조·문서·테스트를 함께 고치고 항목마다 문제와 근거를 적는다.
4. 요구사항·유지 대상·기준 자료와 결과물을 대조한다.
   - 지정된 수정 항목만 고친 작업이면 요구사항 전체를 다시 대조하고 이번 수정으로 영향을 받는 항목만 결과를 갱신한다.
5. 결과물 경로, 구현 근거, 대조 결과를 반환한다.
