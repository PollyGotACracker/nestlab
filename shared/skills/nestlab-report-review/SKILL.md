# 조사 검토

## 절차

1. 보고할 검토 항목을 순서대로 놓는다.
   - 다른 항목의 전제가 되는 항목을 앞에 둔다.
   - 한 번에 한 항목만 보고하고 항목마다 선택을 따로 받는다.
2. 안은 기호만으로 부르지 않고 안마다 아래 네 칸을 적는다.
   - 대상 파일: 바꿀 파일 경로
   - 현재 동작: 지금 원문이나 동작과 그 근거 위치
   - 바꿀 동작: 안을 택했을 때의 원문이나 동작
   - 사례: 안이 적용되는 입력과 결과 한 가지
   - 요구나 확정 사항을 충족하지 못하는 안과 모든 판단 기준에서 다른 안보다 불리한 안은 `제외한 안`에 근거와 함께 적는다.
   - 검토 안과 제외한 안은 모두 문제를 해결하는 안으로만 세운다.
3. 안마다 선택지를 둔 질문 도구로 묻는다. 질문 도구가 없는 환경에서는 같은 내용을 메시지로 묻는다.
4. 보고 서두에 `검토 <전체 개수>개 중 <번호>번째`를 쓴다.
   - 전체 개수는 보고 시작 시점에 확정한 항목 수이다.
5. 사용자가 이미 판정한 사안은 새 근거가 생겼을 때만 다시 보고한다.
   - 다시 보고할 때는 새 근거와 바뀌는 결론만 적는다.

## Template

```markdown
## 검토 <전체 개수>개 중 <번호>번째: <항목 이름>

<요구와 확정 사항에 따라 정해진 전제 한 문단>

### 제외한 안

- <안 이름>: <제외 근거>

### 안 <번호>. <안 이름>

- 대상 파일: <경로>
- 현재 동작: <현재 원문 또는 동작> (`<파일:행>`)
- 바꿀 동작: <바꿀 원문 또는 동작>
- 사례: <입력과 결과>
- 장점: <내용> (출처: <근거>)
- 단점: <내용> (출처: <근거>)

### 추천 안

<추천하는 안과 근거 한 문단>
```
