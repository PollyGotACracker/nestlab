# 조사 검토

## 보고 절차

1. 보고할 검토 항목을 순서대로 놓는다.
   - 다른 항목의 전제가 되는 항목을 앞에 둔다.
   - 추가 제안은 필요한 조사와 후보 설명을 갖춘 뒤 보고한다.
2. 조사 원문의 비교표와 안 블록을 고치지 않고 명세 문서 검토 보고 절의 `#### 검토 <번호>. <항목 이름>` 아래에 옮긴다.
   - 비교표는 모든 안 이름을 행으로 두고 판단 기준별 충족 여부를 칸에 적는다.
   - 안 블록은 안마다 `##### 안 <번호>. <안 이름>` 제목으로 쓴다.
3. 응답에 보고 서두와 같은 비교표 및 안 블록을 옮겨 쓴다.
4. 응답 끝에 `검토 <번호>. <항목 이름>: <정할 대상>을 정한다.` 질문을 질문 도구로 한 번 띄운다.
   - 선택지 라벨은 `안 <번호>. <안 이름>` 형식이고 안 번호 순서와 같다. 2~3개이다.
   - 요구와 확정 사항을 충족하는 안이 하나면 그 안과 제외한 안의 근거를 보고한 후, 선택지 `안 1. <안 이름>`, `폐기`, `재조사` 세 개를 띄운다.
     수정은 질문 도구의 자유 입력으로 받는다.
   - 질문 도구가 없는 환경에서는 같은 문장을 메시지로 묻는다.
5. 보고 서두에 `검토 <전체 개수>개 중 <번호>번째`를 쓴다.

## 보고 규칙

- 한 번에 한 항목만 보고하고 항목마다 선택을 따로 받는다.
- 안은 3개 이하로 세운다.
- 후보 선택에 영향을 주는 잠재 위험과 한계는 선택 전에 보고하고 실행 승인 요청에도 반영한다.
- 질문은 마침표로 끝나는 서술문으로 쓴다.
- 보류와 추가 조사는 선택지 없이 직접 입력으로 받고, hook은 이 답과 `재조사` 답을 기록에서 제외한다.
- 요구나 확정 사항을 충족하지 못하는 안과 모든 판단 기준에서 다른 안보다 불리한 안은 `제외한 안`에 근거와 함께 적는다.
- 검토 안과 제외한 안은 모두 문제를 해결하는 안으로만 세운다.
- 전체 개수는 보고 시작 시점에 확정한 항목 수이다.
- 사용자가 이미 판정한 사안은 새 근거가 생겼을 때만 다시 보고한다.
  다시 볼 때는 새 근거와 바뀌는 결론만 적는다.

## Template

```markdown
## 검토 <전체 개수>개 중 <번호>번째: <항목 이름>

<요구와 확정 사항에 따라 정해진 전제 한 문단>

### 제외한 안

- <안 이름>: <제외 근거>

### 비교표

| **안**    | **<판단 기준>** |
| :-------- | :-------------- |
| <안 이름> | <충족 여부>     |

<명세 문서 검토 보고 절의 안 블록을 안마다 옮긴다.>

### 추천 안

<추천하는 안과 근거 한 문단>

검토 <번호>. <항목 이름>: <정할 대상>을 정한다.
```
