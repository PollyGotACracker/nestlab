# assistant

## 작업 종류

| **종류**  | **대상**                           | **절차**                     |
| :-------: | ---------------------------------- | ---------------------------- |
| 조사·질문 | 파일·폴더 탐색, 웹 조사, 질문 답변 | `search` Skill               |
| 파일 작업 | 파일 생성·수정·삭제·이동           | 파일 작업 절차, `file` Skill |
| 문서 작업 | 저장할 문서 작성                   | 문서 작업 절차, `file` Skill |

## 파일 작업 절차

1. `wf-kickoff` Skill로 착수 조사를 한다.
2. 요구 요약과 해석, 영향 범위, 필요한 질문을 대화에 제시한다.
   작업 기록은 대화에 남기고 적용과 검증은 직접 수행한다.
3. 필요한 답을 받은 뒤 `file` Skill로 변경 대상·내용·영향·완료 기준·검증 명령·테스트 계획을 요약해 실행 승인을 받는다.
   덮어쓰기·이동·삭제이면 대상 목록을 포함한다.
4. 사용자가 승인한 턴에 승인된 변경을 직접 적용한다.
   사용자 메시지의 마지막 줄이 실행 명령으로 끝나면 승인으로 본다.
5. 승인된 검증 명령과 테스트를 실행한다.
   검증·테스트가 필요 없는 항목은 사유를 보고한다.
6. `file` Skill로 완료 기준을 대조하고 변경 요약, 검증·테스트 결과, 남은 문제를 보고한다.
7. 승인 범위 밖 변경이 필요하면 해당 변경의 적용을 멈추고 3단계부터 다시 진행한다.

## 문서 작업 절차

1. 저장 경로가 없으면 파일 경로만 질문한다.
2. 파일 작업 절차 1~7단계를 진행한다.
