# assistant 메인 세션 작업

## 작업별 절차

### 해결안 제안

- 입력: 해결할 문제나 개선 요청, 도구, 라이브러리나 서비스의 사용 목적과 제약
- 필수 사용 스킬: `nestlab-kickoff`

### 저장소 탐색

- 입력: 확인할 파일, 폴더, 설정이나 기록과 질문
- 필수 사용 스킬: `nestlab-kickoff`

### 조사와 질문

- 입력: 조사할 대상이나 질문
- 필수 사용 스킬: 없음
- 권장 사용 스킬:
  - 저장소 확인: `nestlab-kickoff`
  - 사실 확인과 정오 판정: `nestlab-verify`

### 파일 작업

- 입력: 생성, 수정, 삭제나 이동할 대상과 기대 결과
- 필수 사용 스킬: `nestlab-kickoff`, `nestlab-implement`

1. 사용자의 요구사항을 확인한다.
2. 변경 대상·내용·영향·완료 기준·검증 명령·테스트 계획을 요약해 실행 승인을 받는다.
3. 승인된 작업을 수행한다.
4. 승인된 검증 명령과 테스트를 실행하고 필요 없는 항목은 사유를 적는다.
5. 완료 기준을 실제 결과와 대조해 판정한다.
   변경 요약, 검증 결과와 남은 문제를 보고한다.
6. 승인 범위 밖 변경이 필요하면 해당 변경의 적용을 멈추고 처음 단계부터 다시 진행한다.

### 문서 작업

- 입력: 저장할 문서의 내용과 결과 경로 (지침과 스킬 문서 제외)
- 필수 사용 스킬: `nestlab-kickoff`, `nestlab-implement`
- 권장 사용 스킬:
  - README: `nestlab-doc-readme`

1. 사용자의 요구사항을 확인한다.
2. 변경 문구, 대상, 영향, 완료 기준과 검증 계획을 제시해 실행 승인을 받는다.
3. 승인된 작업을 수행한다.
4. 승인된 검증 명령과 테스트를 실행하고 필요 없는 항목은 사유를 적는다.
5. 완료 기준과 서식을 대조해 판정한다.
   변경 위치, 근거와 남은 문제를 보고한다.
6. 승인 범위 밖 변경은 적용을 멈추고 대상과 영향을 조사한 뒤 처음 단계부터 다시 진행한다.

### 지침과 스킬 작업

- 입력: 지침이나 스킬 문서의 변경 요청
- 필수 사용 스킬: `nestlab-kickoff`, `nestlab-rule`

1. `nestlab-rule` 스킬의 절차로 요구사항과 기존 원문을 대조하고 기존 규칙과의 중복과 충돌을 확인한다.
2. 변경 문구, 대상, 영향, 완료 기준과 검증 계획을 제시해 실행 승인을 받는다.
3. 승인된 작업을 수행한다.
4. 승인된 검증 명령을 실행하고 필요 없는 항목은 사유를 적는다.
5. 완료 기준과 서식을 대조해 판정한다.
   변경 위치, 근거와 남은 문제를 보고한다.
