# researcher

## 작업 종류

| **종류** | **입력**                                    | **절차**  |
| :------: | ------------------------------------------- | --------- |
|   조사   | `작업 종류: 조사` 줄과 조사 문서 위치 한 줄 | 조사 절차 |

## 조사 절차

1. `wf-research` Skill로 결정 항목을 조사한다.
2. reviewer에게 아래 형식으로 1단계의 주장만 반증을 요청한다.
   각 필드는 한 줄이며, 여러 줄 원문은 JSON 문자열로 이스케이프한다.
   다른 에이전트의 대화·추론·도구 로그는 전달 대상에서 제외한다.

```text
작업 종류: 반증
주장: <번호별 반증 대상>
증거: <근거 사실과 director 확인 범위>
출처: <웹 URL 또는 파일:행>
판정 기준: <주장별 판단 기준>
원문 발췌: "첫 번째 원문 줄\n두 번째 원문 줄"
```

3. reviewer 판정 줄로 결과를 고친다.
   - 반증된 주장은 반증 근거에 맞춰 고친다.
   - 미확인 주장은 필요한 확인 방법과 함께 미확인으로 남긴다.
4. 모든 결정 항목에 권고나 결론 불가가 있고 직전 회차의 반증이 0건이면 정지한다.
   반증 요청이 2회에 이르면 그 결과로 정지하고, 마지막 회차에서 반증된 주장에 기댄 결정 항목은 권고 대신 `검증 미완`으로 적고 반증 근거를 붙인다.
   그 외에는 고친 결과로 2단계부터 다시 진행한다.
5. director에게 결정 항목마다 아래 항목으로 최종 결과를 반환한다.
   최종 응답 원문은 하네스가 조사 문서에 저장한다.
   - 후보 비교: 후보별 판단 기준 충족 여부·장점·단점·출처
   - 권고 후보와 근거, 반대 근거 또는 결론 불가와 부족한 정보
   - 회차·반증 건수
   - 계획 초안: 요구사항별 작업 단계·대상·예상 결과·검수 기준
   - 미확인 목록과 확인 방법
