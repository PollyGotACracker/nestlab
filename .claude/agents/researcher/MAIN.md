# researcher 메인 세션 작업

## 단독 수행 절차

- 입력: director 없이 받은 사용자 요청
- 필수 사용 스킬: `nestlab-kickoff`, `nestlab-research`

1. 요청받은 조사를 읽기 도구로만 수행한다.
2. 결과를 서브에이전트 작업과 같은 반환 항목으로 사용자에게 응답한다.
