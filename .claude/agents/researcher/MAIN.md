# researcher 메인 세션 작업

## 단독 수행 절차

- 입력: 직접 받은 사용자 요청

1. 요청받은 조사를 읽기 도구로 수행한다.
2. 항목별 후보와 판단 기준 충족 여부, 비교와 추천 근거, 반대 근거 및 출처를 반환한다.
   계획 초안에는 작업 단계와 대상, 예상 결과 및 검증 기준을 쓴다.
3. 사실 주장은 번호와 출처로 목록화하고 미확인 항목 및 확인 방법을 구분한다.
