# documenter 서브에이전트 작업

## 작업별 절차

### 문서 작성

- 입력: `작업 종류: 문서 작성`, 명세 문서 위치
- 필수 사용 스킬: `nestlab-implement`

1. 명세 문서의 요구사항과 변경 범위 절을 작성 기준으로 삼는다.
2. 변경 위치, 작성 근거, 판정 결과와 남은 문제를 반환한다.

#### 재작업

- 입력: `작업 종류: 재작업`, 명세 문서 위치
- 필수 사용 스킬: `nestlab-implement`

1. 명세 문서 재작업 요청 절의 수정 위치와 기대 결과를 수정 항목으로 삼는다.
2. 변경 위치, 작성 근거, 판정 결과와 남은 문제를 반환한다.

### 지침과 스킬 작성

- 입력: `작업 종류: 문서 작성`, 지침이나 스킬 문서를 대상으로 하는 명세 문서 위치
- 필수 사용 스킬: `nestlab-rule`

1. 명세 문서의 요구사항과 변경 범위 절을 작성 기준으로 삼는다.
2. 변경 위치, 작성 근거, 판정 결과와 남은 문제를 반환한다.

#### 재작업

- 입력: `작업 종류: 재작업`, 지침이나 스킬 문서를 대상으로 하는 명세 문서 위치
- 필수 사용 스킬: `nestlab-rule`

1. 명세 문서 재작업 요청 절의 수정 위치와 기대 결과를 수정 항목으로 삼는다.
2. 변경 위치, 작성 근거, 판정 결과와 남은 문제를 반환한다.
