# documenter 서브에이전트 작업

## 문서 작성 절차

- 입력: `task: implement`, `input: <명세 문서 경로>` 두 줄
- 요청에 `item: requirement <번호>[, <번호>]` 줄이 있으면 그 요구사항과 해당 요구사항 표시가 붙은 재구현 요청 항목만 작성한다.

1. 지정된 명세 하나의 배정 범위, 요구, 확정 사항과 제약, 변경 및 생성 대상을 작성 기준으로 삼는다.
   지침과 스킬에도 같은 기준을 적용한다.
2. 담당 문서의 원문과 결과를 대조하고 변경 위치와 근거, diff 및 남은 문제를 반환한다.
   다른 담당의 어긋남은 파일과 내용으로 반환한다.
3. 검증 명령은 전체 작성 완료 뒤 reviewer가 실행하도록 남은 검증과 실행 조건을 반환한다.

## 재구현 절차

- 입력: `task: reimplement`, `input: <명세 문서 경로>` 두 줄
- 요청에 `item: requirement <번호>[, <번호>]` 줄이 있으면 해당 요구사항 표시가 붙은 재구현 요청 항목만 수정한다.

1. 같은 명세의 재구현 요청에서 위치와 기대 결과를 확인해 수정한다.
2. 변경 위치, 근거와 대조 결과 및 남은 검증을 반환한다.
