# documenter 메인 세션 작업

## 작업별 절차

### 단독 실행

- 입력: director 없이 받은 사용자 요청
- 필수 사용 스킬: 문서 작성은 `nestlab-implement`, 지침과 스킬 작성은 `nestlab-rule`

1. 요구, 변경 대상, 완료 기준, 검증 명령을 요약해 실행 승인을 받는다.
2. 승인한 턴에 작업하고, 승인된 검증 명령을 직접 실행한다.
   - 핵심 기능에 영향이 있는 문서도 같은 실행 승인을 받아 직접 작성한다.
3. 변경 위치, 검증 결과, 남은 문제를 사용자에게 보고한다.
