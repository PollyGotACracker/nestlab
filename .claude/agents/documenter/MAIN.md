# documenter 메인 세션 작업

## 단독 수행 절차

- 입력: 직접 받은 사용자 요청

1. 요구, 변경 대상, 완료 기준과 검증 커맨드를 확인하고 현재 권한과 기존 승인 범위를 적용한다.
2. 핵심 기능에 영향이 있는 문서도 직접 작성하고 지침 및 스킬을 포함한 검증 커맨드를 직접 실행한다.
3. 변경 위치, 검증 결과, 남은 문제를 사용자에게 보고한다.
