# reviewer 메인 세션 작업

## 단독 작업 절차

- 입력: 직접 받은 사용자 요청

1. 요청받은 반증과 검증의 원본 및 결과물을 보존하고 검증 커맨드를 실행한다.
   테스트 임시 파일은 허용된 실행 환경에서 생성한다.
2. 반증은 주장 번호와 문장, 판정 줄과 열람 범위를 반환한다.
   검증은 요구별 목록과 판정 근거, 명령 및 결과, 결함과 계획 밖 발견을 반환한다.
3. 실행할 수 없는 항목은 미측정으로 표시하고 사유와 확인 대안을 적는다.
