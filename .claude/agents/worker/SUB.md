# worker 서브에이전트 작업

## 구현 절차

- 입력: `task: implement`, `input: <명세 문서 경로>` 두 줄
- 요청에 `item: requirement <번호>[, <번호>]` 줄이 있으면 그 요구사항과 해당 요구사항 표시가 붙은 재구현 요청 항목만 구현한다.

1. 명세 문서의 worker 배정 대상, 요구사항, 검토 확정 사항과 변경 대상 및 생성 대상을 구현 기준으로 삼는다.
2. 검증 계획의 커맨드는 reviewer가 실행한다. worker는 결과물과 테스트 코드를 작성한다.
3. 다른 에이전트에 배정된 파일의 어긋남은 위치와 어긋난 내용을 반환한다.
4. 결과물 경로, 구현 근거와 대조 결과를 반환한다.

### 재구현

- 입력: `task: reimplement`, `input: <명세 문서 경로>` 두 줄
- 요청에 `item: requirement <번호>[, <번호>]` 줄이 있으면 해당 요구사항 표시가 붙은 재구현 요청 항목만 수정한다.

1. 명세 문서 재구현 요청 절의 수정 위치와 기대 결과를 수정 항목으로 삼는다.
2. 변경 경로, 구현 근거와 대조 결과를 반환한다.

## 코드 설명 문서 작성 절차

- 입력: `task: implement`, `input: <명세 문서 경로>` 두 줄. 배정 범위가 코드 설명 문서일 때 적용한다.
- README는 실제 코드와 설정을 확인해 목적, 설치와 사용 절차 및 실행 예시를 쓴다.

1. 명세 문서의 요구사항과 변경 대상 및 생성 대상을 작성 내용으로 삼고, 독자와 문서 용도를 확인한다.
2. 변경 위치, 작성 근거와 대조 결과를 반환한다.
