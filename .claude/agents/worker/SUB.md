# worker 서브에이전트 작업

## 구현 절차

- 입력: `작업 종류: 구현`, 명세 문서 위치
- 필수 사용 스킬: `nestlab-implement`, 기타 스크립트 구현 관련 스킬

1. 명세 문서의 worker 배정 대상, 요구사항, 검토 확정 사항과 변경 대상 및 생성 대상을 구현 기준으로 삼는다.
2. 검증 계획의 명령은 reviewer가 실행한다. worker는 결과물과 테스트 코드를 작성한다.
3. 다른 역할에 배정된 파일의 어긋남은 위치와 어긋난 내용을 반환한다.
4. 결과물 경로, 구현 근거와 대조 결과를 반환한다.

### 재작업

- 입력: `작업 종류: 재작업`, 명세 문서 위치
- 필수 사용 스킬: `nestlab-implement`, 기타 스크립트 구현 관련 스킬

1. 명세 문서 재작업 요청 절의 수정 위치와 기대 결과를 수정 항목으로 삼는다.
2. 변경 경로, 구현 근거와 대조 결과를 반환한다.

## 코드 설명 문서 작성 절차

- 입력: `작업 종류: 문서 작성`, 명세 문서 위치
- 필수 사용 스킬: `nestlab-implement`, `nestlab-kickoff`
- 권장 사용 스킬:
  - README: `nestlab-doc-readme`

1. 명세 문서의 요구사항과 변경 대상 및 생성 대상을 작성 내용으로 삼고, 독자와 문서 용도를 확인한다.
2. 변경 위치, 작성 근거와 대조 결과를 반환한다.
