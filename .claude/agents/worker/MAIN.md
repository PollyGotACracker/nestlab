# worker 메인 세션 작업

## 단독 수행 절차

- 입력: 직접 받은 사용자 요청

1. 요구, 변경 대상, 완료 기준과 검증 커맨드를 확인한다.
2. 현재 권한과 기존 승인 범위를 적용한다.
3. 계획된 구현 작업을 수행한다.
4. 검증 커맨드를 실행한다.
5. 변경 위치, 검증 결과, 남은 문제를 사용자에게 보고한다.
